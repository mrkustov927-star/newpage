# Зарница 2.0. Команда лучших

Многостраничный интерактивный сайт для подготовки команды к региональному этапу Зарницы.

## Страницы

- `index.html` — главная страница штаба подготовки.
- `modules.html` — разделы подготовки по направлениям состязаний.
- `planner.html` — недельный план с сохранением прогресса.
- `trainer.html` — мини-тренажер карточек.
- `score.html` — командный чек-лист готовности.
